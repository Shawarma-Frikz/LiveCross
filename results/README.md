# Results and Reproducibility

Store reproducible audit reports, experiment tables, plots, and failure-case summaries here. The tracked `audits/dot-sample-audit.json` is generated by `python scripts/audit_sample_data.py`. The tracked `audits/supplemental-dataset-audit.json` is generated by `python scripts/audit_supplemental_data.py`. Both scripts inspect local files in Git-ignored `data/raw/` and download nothing.

For every reported experiment result, include the configuration, data/run IDs, split, random seed, model version, dependencies, hardware, and metric denominators. Keep raw video out of this folder and do not report event-level scores against run-level labels. Generated reports must distinguish automated measurements from human interpretation.
